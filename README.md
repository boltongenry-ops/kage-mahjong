# Kage · Путь ронина

Монохромная японская головоломка: собирайте тройки, освобождайте поле и восстанавливайте забытое святилище.

**Играть:** https://kage-ronin.aerialatoll.chatgpt.site

## Возможности

- 500 фиксированных уровней, 10 глав, 30 семейств раскладок; каждое решение проверено отдельно от игрового движка.
- Путь ронина, Дзен (9 ячеек), Испытание клинка (120 секунд), Задание дня (московская дата).
- Бесплатные отмена, подсказки и перезапуск. Нет рекламы, платежей или ограничения попыток.
- 50 этапов восстановления святилища, звёзды, календарь и личный рекорд.
- Русский интерфейс, вертикальная композиция 9:16, собственные векторные иллюстрации и 18 символов.
- PWA, офлайн после полной первой загрузки, сохранение каждого хода в IndexedDB, резервная запись, экспорт/импорт JSON.

## Запуск

Node.js 24:

```sh
npm ci
npm run dev
```

```sh
npm test
npm run validate
npm run build
node scripts/check-build.mjs
```

Для статического HTTPS-хостинга опубликуйте содержимое `dist/` в корень домена. Service worker генерируется при сборке и кэширует все необходимые ресурсы. Новая версия устанавливается из настроек между партиями. Для разработки офлайн-кэш не регистрируется, если файл sw.js отсутствует.

`npm run generate` воспроизводит закреплённые уровни из стабильных seed. `npm run icons` собирает PNG-иконки из SVG. `docs/level-validation.json` содержит результат независимой проверки.

## Правила

Нажмите на плитку, не перекрытую сверху. Она попадёт в лоток. Три одинаковых символа исчезают; тройка сначала разрешается, затем проверяется заполнение лотка. Семь плиток без тройки завершают попытку. В Дзен при заполнении девяти ячеек можно бесплатно отменить ход. Отмена восстанавливает полное предыдущее состояние, включая исчезнувшую тройку.

Кампания выдаёт 1 звезду за победу, +1 без отмен, +1 без подсказок. Любая победа открывает следующий уровень. Каждые 10 впервые пройденных уровней восстанавливают часть святилища. Испытание даёт 100 очков за тройку, сохраняет суммарный счёт между полями и приостанавливается при сворачивании. Ежедневная головоломка одинакова для данной московской даты и использует проверенную библиотеку.

Подсказки работают в Web Worker. Для известного пути используется сертификат, для другого состояния — поиск с лимитом времени. Отсутствие найденного решения не выдаётся за доказательство невозможности.

## Архитектура

- `src/engine.ts`: чистые правила, состояние, генератор случайных чисел и поиск решения.
- `src/main.ts`: экраны, переходы, режимы и ввод; `src/storage.ts`: IndexedDB и импорт.
- `scripts/`: генерация, независимая проверка, PWA-пакет и проверка офлайн-ресурсов.

`LevelDefinition` хранит геометрию, символы и сертификат решения. `GameState` хранит оставшиеся плитки, лоток, историю, режим и таймер. `SaveData` версии 1 объединяет сессии, результаты и настройки. Чужие версии импорта отклоняются; ранее выпущенных форматов для миграции нет.

## Проверка и ограничения

14 автоматических тестов: все 500 решений на рабочем движке, крайние случаи лотка и отмены, подсказки, московская дата, IndexedDB, импорт, очереди записи и DOM-сценарий всех экранов и режимов. Отдельный валидатор проверяет 500 сертификатов; проверка сборки исполняет service worker с имитацией отключённой сети.

DOM-тест не заменяет настоящий браузер. В среде сборки не был доступен инструмент браузерной проверки; визуальная проверка Safari/Chrome на физических телефонах, реальная установка PWA и ручная оценка баланса остаются непроверенными. Прогресс локальный: очистка данных браузера удаляет его; используйте экспорт. Нет облачной синхронизации, аккаунтов и сетевых рейтингов. Атмосферная музыка синтезируется на устройстве, вибрация зависит от браузера.
